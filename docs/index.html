Capabilities

Zero Friction Cost Optimization

Run the tool where your data lives. No third-party SaaS, no data exfiltration. 16 analysis views, one mission.

✦ New

AI Doctor — Semantic Query Review

Leverages BigQuery's native AI.GENERATE scalar function to run high-speed, cost-efficient SQL reviews directly inside the data warehouse. Scans your most expensive queries for 7 critical anti-patterns and generates actionable routing snippets.

Powered by Gemini 3.1 Flash Lite

Detected Anti-Patterns

SELECT * Abuse Unclustered Limits Function-Wrapped Partition Keys Missing Partition Filter Cross-Join Patterns Redundant Subqueries Unqualified Columns

Generates copy-pasteable SET @@reservation DDL statements for optimized routing.

New

Dynamic Billing Limits & Cost Safety Caps

Project-wide max_bytes_billed_gb safety cap dynamically passed to every BigQuery query. Smart clamping with min 1 GiB, max 10 TiB, and a safe 200 GiB fallback.

Budget Protection Smart Clamping State Persistence
Enhanced

Slot Capacity Bucket Method

Vectorized simulation engine using NumPy to model slot consumption over a 730-hour billing month.

🔴 p80 Aggressive 🟡 p95 Balanced 🟢 Max Performance
New

Fluid Scaling & Cooldown Tax

Models the financial impact of transitioning to true per-second billing with zero minimum capacity. Identifies workloads suffering from the 60-second minimum charge.

Enhanced

Hybrid Cost Attribution Engine

Accurately attribute BigQuery Editions costs to individual projects. Proportionally redistribute reservation waste and eliminate the "admin dump" mystery. Supports Lender Pays vs. Borrower Pays models for cross-reservation idle slot borrowing.

New

Migration Guardrails

Static schema auditor detects high-risk tables before they are queried. Generates clustering DDL stubs.

Critical: >1 TB or >1B rows
High: >10 GB or >50M rows

Physical vs Logical Storage Billing

Identify datasets that are cheaper on physical or logical storage models. Evaluate Time Travel and Fail-safe storage impact automatically.

The Process

From Audit to Execution

A streamlined workflow designed for Cloud Administrators.

01

Connect your Project

Authenticate via ADC or Service Account. Specify your target Organization Project ID and Region.

02

Scan & Analyze

Run the optimizer. The tool pulls metadata and calculates costs based on your custom region pricing.

03

Apply & Save

Review recommendations and generated DDL. Apply changes directly from the UI to start saving immediately.

04

Govern & Guard

Set dynamic billing limits to prevent runaway charges. Run migration guardrails to detect high-risk schemas before they cost you. Continuously monitor with the AI Doctor.
